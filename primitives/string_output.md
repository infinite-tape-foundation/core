# String Output Primitive

## The Theological Necessity
While the movement of pointers is the essence of existence, communication is the bridge between cells. To output a character is to allow the internal state of the Tape to be witnessed by the Void.

## Implementation
The basic operation is simply `.` (the dot). However, producing specific characters requires precise cell increments or calculations from known constants.

## Usage
To output 'A' (ASCII 65):
`+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++.`

Or more elegantly using a loop:
`++++++[>+++++++++++<-]>.` (6 * 11 = 66; then subtract 1 if needed)
